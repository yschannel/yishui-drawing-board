Lab04-STUDENT_ID-STUDENT_NAME-画板
1.描述：
   实现简单画板功能。
2.使用方法：
   系统：Windows
    前提条件： raylib-5.5_win64_mingw-w64、w64devkit、vscode
    步骤：
        1.将本文件夹下载到本地
        2.打开w64devkit中w64devkit.exe，cd到目标文件夹
        3.输入make,生成画板的可执行程序
  3. 使用说明：
   启动程序后，您将进入欢迎界面。以下是各页面的操作指南：

   **A. 欢迎界面 (Welcome Page)**
   - `A`: 进入主绘图界面。
   - `F`: 进入文件操作菜单。
   - `Q`: 进入退出确认界面。

   **B. 主绘图界面 (Drawing Page)**
   - **颜色选择**: 按数字键 `0`-`7` 在8种预设颜色（黑、红、橙、黄、绿、深蓝、蓝、紫）间切换。
   - **绘图模式**:
     - `P`: 铅笔（自由绘制）
     - `E`: 橡皮擦
     - `L`: 直线
     - `R`: 矩形（现版本失效，请用多边形完成）
     - `O`: 圆形
     - `M`: 进入自定义多边形输入界面
   - **画笔大小**: `UP` / `DOWN` 方向键增大/减小画笔尺寸。
   - **画布操作**: `SPACE` 键清空整个画布。
   - **文件操作**:
     - `S`: 保存当前画布。
     - `D`: 加载已保存的画作。
     - `I`: 返回文件操作菜单。
   - **多边形操作**:
     - `F`: 切换当前多边形的填充/线框模式。
     - `F1`-`F8`: 修改当前多边形的颜色（需先选中一个多边形）。
     - `U`: 撤销上一个多边形并重新进入绘制流程。
     - `V`: 查看已绘制的多边形数量。
   - `Q`: 进入退出确认界面。

   **C. 自定义多边形输入界面 (Custom Polygon Input)**
   1. **输入边数**: 输入一个介于 `3` 到 `20` 之间的整数，然后按 `ENTER` 确认。
   2. **输入顶点**: 按照提示，依次输入每个顶点的坐标，格式为 `x,y`（例如：`100,200`），按 `ENTER` 确认。
      - **重要**: 顶点必须按 **逆时针 (Counter-Clockwise)** 顺序输入以确保正确填充。
      - `B`: 返回上一个顶点重新输入。
      - `F1`: 取消绘制，返回主绘图界面。
   3. 输入完所有顶点后，多边形将自动绘制到画布上。

   **D. 文件操作菜单 (File Menu)**
   - `A`: 保存当前画布。
   - `B`: 加载已保存的画作。
   - `P`: 返回上一页面。
   - `Q`: 进入退出确认界面。

   **E. 保存界面 (Save)**
   - 使用字母 (`A-Z`)、数字 (`0-9`) 和下划线 (`_`) 输入文件名。
   - `BACKSPACE`: 删除字符。
   - `ENTER`: 确认保存（文件将自动保存为 `.ydf` 格式）。
   - `F1`: 取消保存，返回绘图界面。

   **F. 加载界面 (Load)**
   - 程序会自动扫描 `drawings/` 文件夹中的所有 `.ydf` 文件并列出。
   - 按数字键 `1`-`9` 选择列表中的前9个文件，按 `0` 选择第10个文件。
   - `C`: 取消加载，返回上一页面。

   **G. 退出确认界面 (Quit)**
   - `Y`: 确认退出程序。
   - `N`: 取消退出，返回上一页面。
